# GrowingCode: Python Fundamentals Through Garden Data

## Part of 42 new curriculum; Python module 00

A hands-on learning experience where you develop core Python programming concepts through practical garden-themed exercises. Each exercise builds upon previous knowledge, creating a solid foundation in Python fundamentals.

---

## 📚 Concepts Explored by Exercise

### **Exercise 0: Hello Garden** 
**Concepts:** Print statements, string output, basic I/O
- Introduction to Python's `print()` function
- Outputting text to the console
- String literals and basic formatting
- Foundation for all future exercises

### **Exercise 1: Plot Area**
**Concepts:** Variables, numeric data types, arithmetic operations, functions
- Variable assignment and naming conventions
- Integer and float data types
- Mathematical operations (multiplication, division)
- Writing and calling functions with return values
- Working with measurements and calculations

### **Exercise 2: Harvest Total**
**Concepts:** Addition, loops, data accumulation, function parameters
- Iterating through collections of values
- Accumulating data using loops
- Using parameters to pass data to functions
- Working with numeric summation
- Introduction to list/array processing concepts

### **Exercise 3: Plant Age**
**Concepts:** Conditional statements, comparison operators, boolean logic
- `if`, `elif`, `else` decision structures
- Comparison operators (`<`, `>`, `==`, `!=`, `<=`, `>=`)
- Boolean expressions and logical evaluation
- Making decisions based on conditions
- Age validation and threshold checking

### **Exercise 4: Water Reminder**
**Concepts:** Conditional logic, status checking, multi-branch decisions
- Complex conditional statements
- Multiple condition checking
- Status evaluation and reporting
- Real-world condition monitoring
- Building decision trees in code

### **Exercise 5: Count Harvest**
**Concepts:** Loops (iterative and recursive approaches), algorithm design, function recursion
- **Iterative version:** `for` and `while` loops, counter variables, iteration patterns
- **Recursive version:** Function recursion, base cases, recursive calls, call stacks
- Understanding different problem-solving approaches
- Time complexity and algorithm efficiency concepts
- Counting and iteration patterns

### **Exercise 6: Garden Summary**
**Concepts:** String formatting, f-strings, data presentation, structured output
- F-string syntax and interpolation
- String concatenation and formatting
- Presenting data in a readable format
- Multi-line output construction
- Combining multiple data points into coherent output

### **Exercise 7: Seed Inventory**
**Concepts:** Type hints, function signatures, type annotations, defensive programming
- Python type hints (`str`, `int`, `None`)
- Type annotations for function parameters and return values
- Understanding function signatures with types
- Handling different input types
- Error handling and validation
- Writing self-documenting code

---

## 🎯 Learning Progression

1. **Basics** (Exercises 0-1): Print statements and basic calculations
2. **Data Processing** (Exercises 2): Working with multiple values
3. **Decision Making** (Exercises 3-4): Conditional logic and control flow
4. **Advanced Loops** (Exercise 5): Iterative and recursive approaches
5. **Output Formatting** (Exercise 6): Presenting data effectively
6. **Type Safety** (Exercise 7): Writing robust, well-documented code

## 🚀 Getting Started

1. Review the exercise requirements in each `ex#` folder
2. Create the required Python files (e.g., `ft_plot_area.py`)
3. Implement the functions according to the specifications
4. Test your work using the helper script:
   ```bash
   python3 .main.py
   ```

Choose an exercise number or enter `a` to test all exercises.
